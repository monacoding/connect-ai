# 📄 페이지 수집 (page_fetcher)

URL 한 개를 열어 HTML에서 읽을 수 있는 본문 텍스트를 추출합니다.

## 어떻게 도와주나요?
- 블로그·뉴스·공지 페이지 본문 빠르게 가져오기
- `web_search` 결과 URL의 상세 내용 확인
- 출처 URL을 그대로 인용 가능한 형태로 출력

## 설정값 (page_fetcher.json)
- `URL` — 수집할 페이지 주소
- `MAX_CHARS` — 최대 추출 글자 수 (기본 8000)

## 한계
- 로그인·페이월·JavaScript 렌더 전용 페이지는 본문이 비거나 짧을 수 있음
- robots.txt·저작권·이용약관을 존중하고 공개 페이지만 수집
