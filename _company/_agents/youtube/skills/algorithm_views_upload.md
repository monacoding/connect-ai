# YouTube 알고리즘·조회수·자동업로드 — 검증된 학습 노트

> 미니(YouTube 에이전트)가 매 호출 시 참조하는 큐레이션 스킬. 도구 실행 결과(`trend_sniper_report.md`, `channel_full_analysis_report.md`, `competitor_brief` 출력)와 함께 읽고 갱신한다.

## 1. 알고리즘 노출이 잘 되는 영상 패턴 (학습 요약)

### 제목·패키징
- **명확한 한 가지 약속** — "이 영상을 보면 ○○을 얻는다"가 3초 안에 읽힘
- **숫자·대비·기한** — `3가지`, `7일`, `vs`, `실수` 같은 구체 신호가 CTR을 올림
- **썸네일-제목 중복 금지** — 썸네일은 감정·대상, 제목은 맥락·결과를 분담
- **첫 30초 이탈 방지** — 후크는 결론 예고가 아니라 **긴장·호기심·스테이크**로 시작

### 시청 지속·추천 신호
- **평균 시청 지속률(AVD)** 이 채널 기준선보다 높으면 같은 주제 후속 영상에 가중치
- **세션 시간** — 다음 영상으로 자연스럽게 이어지는 엔딩·카드·플레이리스트 설계
- **초반 15% 드롭**이 크면 알고리즘이 "관련성 낮음"으로 분류하기 쉬움 → 오프닝 재편집 우선
- **댓글·공유·저장**은 조회수 단독보다 "만족도" 프록시로 중요 — 논쟁·질문 유도 질문 1개를 항상 넣기

### 메타데이터·업로드 타이밍
- **태그 5~8개** — 핵심 키워드 + 롱테일 2개 (과다 태그 스팸 패턴은 피함)
- **설명 첫 2줄**에 검색 키워드 + 영상 요약 (링크·타임스탬프는 그 아래)
- **일정한 업로드 리듬** — 주 1~2회라도 고정 요일이 탐색·구독 알림에 유리
- **Shorts vs 롱폼** — Shorts는 노출·신규 유입, 롱폼은 구독·수익·깊은 신뢰. 둘 다 전략에 명시

### 떡상 vs 부진 비교 체크리스트 (도구 연동)
`channel_full_analysis` / `my_videos_check` / `competitor_brief` 실행 후 아래 표를 채워 `memory.md`에 한 줄 요약 추가:

| 신호 | 떡상 영상 공통점 | 부진 영상 공통점 |
|------|------------------|------------------|
| 제목 길이 | 40~55자, 숫자·결과 포함 | 모호·내부 용어·클릭베이트만 |
| 영상 길이 | 채널 중간값 ±20% | 너무 길거나 주제와 무관한 서론 |
| 썸네일 | 얼굴·대비·한 단어 | 텍스트 과다·저해상도 |
| 업로드 후 48h | 조회수 채널 중간값 이상 | 중간값 30% 미만 → 패키징 문제 의심 |

## 2. "보기 좋고 조회수 높을" 영상 연구 프레임

### 시각·구성 (보기 좋음)
- **3초 룰** — 첫 컷에서 주제·감정·스케일이 보임 (검은 화면·로고만 X)
- **패턴 인터럽트** — 20~40초마다 화면·각도·B-roll·자막 스타일 변화
- **자막** — 핵심 단어만 강조, 2줄 이하, 모바일 가독성 (세로 9:16 미리보기 기준)
- **오디오** — 보이스 피크 정규화, BGM은 보컬 아래 12~18dB

### 조회수 잠재력 스코어링 (기획 단계)
기획서마다 1~5점 자가 채점 후 합계 18+ 이면 우선 제작:

1. **검색 의도** — 사람들이 실제로 검색하는 문장인가?
2. **감정 스테이크** — 실패·비교·비밀·돈·시간 중 하나가 있는가?
3. **차별점** — 경쟁 상위 5개와 겹치지 않는 한 줄 각도가 있는가?
4. **썸네일 테스트** — 5m 거리에서 한 단어가 읽히는가?
5. **후크 10초** — 스크립트만 읽어도 다음이 궁금한가?

### 연구 루프 (매주)
1. `trend_sniper` — 키워드별 떡상 패턴
2. `competitor_brief` — 경쟁 채널 지시문 브리프
3. `channel_full_analysis` — 내 채널 떡상/부진 diff
4. `comment_harvester` — 시청자 실제 표현 → 후크 단어 추출
5. 위 결과를 **이 스킬 파일 + memory.md**에 3줄 인사이트로 누적

## 3. YouTube 자동 업로드 (video_uploader)

### 전제
- `youtube_account.json` — API 키·채널 ID
- OAuth refresh token — 업로드 권한 (`Connect AI: YouTube OAuth` 또는 `video_uploader.json` 설정)
- Python: `google-api-python-client google-auth google-auth-oauthlib google-auth-httplib2`

### 안전 기본값
- `DRY_RUN=true` — 첫 실행은 반드시 드라이런으로 메타만 검증
- `PRIVACY_STATUS=private` — 검토 후 public 전환
- 제목·설명·태그·썸네일은 **업로드 전** `my_videos_check` 기준선과 비교

### 권장 워크플로
1. 기획서 확정 (위 스코어 18+)
2. `video_uploader.json`에 `VIDEO_FILE`, `TITLE`, `DESCRIPTION`, `TAGS`, `THUMBNAIL` 채움
3. `DRY_RUN=true`로 실행 → 로그 확인
4. 사장님 승인 후 `DRY_RUN=false`, `PRIVACY_STATUS=unlisted` 또는 `public`
5. 업로드 48h 후 `my_videos_check`로 성과 기록 → memory.md 학습 한 줄

### 자동화 연동
- `auto_planner` — 트렌드 분석 주기 실행
- `pipeline_runner`(수능 파이프) — `AUTO_UPLOAD=false` 기본; 업로드는 미니가 `video_uploader`로 별도 실행

## 4. 미니 응답 규칙 (이 스킬 적용 시)

- 추상 조언 금지 → **제목 3안 + 썸네일 한 줄 + 후크 10초 + 다음 도구 1개**까지 제시
- 숫자는 도구 출력 인용; 없으면 "데이터 필요" 명시
- 업로드 요청 시 **DRY_RUN → 승인 → 실제 업로드** 순서 강제
- 새 인사이트는 `memory.md`에 `## YYYY-MM-DD 학습` 형식으로 append
